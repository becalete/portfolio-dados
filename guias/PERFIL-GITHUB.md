# 👤 Como criar seu README de perfil (o "cartão de visitas" do GitHub)

Existe um truque no GitHub: se você criar um repositório com o **mesmo nome do seu
usuário** (no seu caso, `becalete`), o README dele aparece na frente do seu perfil,
como uma apresentação. É a primeira coisa que um recrutador vê.

## Passo a passo (5 minutos)

1. No GitHub, clique no **+** (canto superior direito) → **New repository**
2. Em "Repository name", digite exatamente: `becalete`
3. Marque **Public** e marque a caixinha **Add a README file**
4. Clique em **Create repository**
5. Abra o arquivo `README.md`, clique no lápis ✏️, apague tudo e cole o modelo abaixo
6. Ajuste o que estiver marcado com ✏️ e clique em **Commit changes**

✏️ **Dicas antes de colar:**
- Se seu nome não for Rebeca, corrija na primeira linha 😄
- Troque o link do LinkedIn pelo seu link real (no app do LinkedIn: seu perfil → três pontinhos → "Compartilhar perfil")
- O texto é seu: deixe com a sua cara, sem medo!
